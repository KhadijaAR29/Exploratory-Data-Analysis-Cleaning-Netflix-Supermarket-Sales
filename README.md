# Exploratory-Data-Analysis-Cleaning-Netflix-Supermarket-Sales
Data Quality Assessment, Cleaning Pipelines, and Univariate EDA for Netflix Catalog and Supermarket Sales Datasets

---

## Overview

This repository contains data quality assessments, cleaning pipelines, exploratory data analysis (EDA), and structured handoff documentation for two core datasets:

1. **Part A: Netflix Movies and TV Shows** — Catalog analysis of content types, release timelines, maturity ratings, and country/genre distributions.
2. **Part B: Supermarket Sales** — Transactional analysis of customer spending patterns, operational timelines, and rating distributions across retail branches.
